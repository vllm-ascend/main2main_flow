## 口径说明

1. **通过率分母随年代变化**：
   - 08 月：mode=all 全量，每 leg 2500~2831（含 UT），以 pytest collected 为分母；
   - 09-03~09-07：单 leg（仅 main），以 pytest outcomes（passed+failed+errors）为分母；
   - 09-12 起：双 leg 各 113/114 精选 e2e（a5-4 的 2 个无 runner 恒 skip，实跑 111）。
2. **每 step 用例数** = flow 日志里的 expanded test 数（7→11→16→18→22→25），`R:` 后为单次调用的内部调度轮分布；flow 日志只记用例级计数，无逐用例通过明细。
3. **全绿 3 个**：#14865、#15348、#15841。**bot run 不可映射 2 个**：#16159（fork 上带外执行）、#16424（PR-CI 监控修复轮手动推送，head commit `main2main: fix PR CI (round-0)`）。
